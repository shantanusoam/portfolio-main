# Appearance review

Capture (via the appearance panel's toggles, not separate code paths):

- silhouette only
- flat colour
- final print
- 96-pixel preview
- fall
- landing
- turn
- rest
- reduced mode

Score 1-10:

- originality
- head readability
- face readability
- body balance
- texture attachment
- colour hierarchy
- motion compatibility
- performance

Record results in `docs/mascot/APPEARANCE_REVIEW.md`. A phase is not
complete when a critical category scores below 6 — see the master plan's
"Quality Review Rubric" for the same convention applied to motion.
