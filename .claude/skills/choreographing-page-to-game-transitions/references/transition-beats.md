# Transition beats

Required order:

1. anticipation (look down, compress, strings dim except the target)
2. release (input detaches, gravity-driven, body stretches, tail lags)
3. controlled tumble (bounded rotation, not constant spin)
4. string contacts (each crossing bends a string and, when enabled, plays
   a note, in time order)
5. landing (squash, impact wave, music resolves)
6. impact recovery (one overshoot, then settle)
7. camera reframe / overlay reveal
8. HUD reveal
9. gameplay ready

Every beat must be interruptible or safely recoverable — a resize, a
route change, or the user hitting Escape mid-transition must not leave the
engine in a broken state.
