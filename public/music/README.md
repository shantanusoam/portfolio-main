# Portfolio Radio

Only place audio here when it is original, licensed, or otherwise safe to
redistribute publicly. Soundroom also includes three tiny procedural records,
generated in the visitor's browser, so an empty manifest is still playable.

Add files in collection folders and list them in `manifest.json`:

```json
{
  "tracks": [
    {
      "id": "my-original-track",
      "title": "Track title",
      "artist": "Artist",
      "album": "Collection",
      "src": "/music/indie/my-original-track.mp3",
      "accent": "#ff6946"
    }
  ]
}
```

Local Library files never use this folder and are never uploaded.
